# Acidification Nearshore Monitoring Network (ANeMoNe) Data 

This folder contains original and processed ANeMoNe data. The Acidification Nearshore Monitoring Network (ANeMoNe) data collection program is run by the Washington Department of Natural Resources Aquatic Assessment and Monitoring Team, with the intent to study climate change, warming waters, and ocean acidification in nearshore marine ecosystems. Scientists and community volunteers maintain in situ autonomous sensors and collect biological information. More information on ANeMoNe can be found on the [Washington spatial data explorer](https://geo.wa.gov/maps/88378419ffa442e48ed8492f68922f60/about) and [ANeMoNe Toolbox](https://storymaps.arcgis.com/stories/8b277d4e0258487ba0254f87a4764ba7) websites. 
The source identifier assigned to ANeMoNe data is 'anemone'.
For PSAI, we used ANeMoNe data on temperature, pH, dissolved oxygen, salinity, and chlorophyll from sites within Puget Sound for data from 03-01-2018 through 09-01-2019. Additional ANeMoNe data will be included if we are able to obtain LiveOcean model output for those years. The sites, longitudes, latitudes, and site names used are as follows:
