# Observations

This folder contains compiled observations, information about the original data sources, preprocessing scripts and methods, quality assurance and quality control procedures, a methods manual for data handling, and original and processed datasets, including source, collection, and quality-control flag information.

## Data Sources

1. [Canada Department of Fisheries and Oceans (DFO)](https://data.cioospacific.ca/erddap/index.html): Data collected via bottle and CTD spanning 1930-2021, by Susan Allen's group. Further information and preprocessing code is available on the [LiveOcean/obs](https://github.com/parkermac/LO/tree/main/obs) GitHub page; identical methods were used here and therefore this code is not replicated within this repository.
