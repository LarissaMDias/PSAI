# Oceanic Remote Chemical Analyzer (ORCA) Data

The [Oceanic Remote Chemical Analyzer (ORCA)](https://nwem.apl.uw.edu/about_proj_ORCA.shtml) is an autonomous moored profiling system consisting of six mooring systems spread throughout Puget Sound. These systems collect real-time measurements of atmospheric and water systems. Data from ORCA can be found on [ERDDAP's NANOOS Server](https://erddap.nanoos.org/erddap/tabledap/index.html?page=1&itemsPerPage=1000) or map-based data visualizations can be accessed on [NANOOS](https://www.nanoos.org). 

PSAI uses ORCA measurements on temperature, salinity, NO3, NH4, TA, DIC, dissolved oxygen, and chlorophyll a concentrations, which span from 09-30-2014 through present day, depending on the station.
